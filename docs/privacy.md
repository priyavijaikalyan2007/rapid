# CropPrint privacy policy

Effective date: 25 August 2026

CropPrint does not require an account. CropPrint does not contain advertising, analytics, tracking, or marketing software.

## Photos and decorations

CropPrint processes photos on your device. CropPrint does not upload your photos, crops, print sheets, frames, or text decorations to a CropPrint server.

On macOS, you select the files that CropPrint can open. CropPrint stores security-scoped bookmarks on your Mac so that the Open Recent menu can restore access.

On iPhone, the system photo picker supplies the photo that you select. CropPrint requests add-only Photos access when you save a crop or print sheet.

## Local storage

CropPrint stores application preferences and downloaded resources on your device. The application does not send these preferences to the developer.

The operating system removes application storage when you delete the application. Exported photos remain until you delete them.

## Remote resources

CropPrint includes an optional resource library for open-source fonts and Creative Commons assets. CropPrint connects only when you refresh a remote catalog or download a resource.

The built-in catalog downloads fonts from the Google Fonts repository on GitHub. GitHub receives normal request information, such as your Internet Protocol address and request headers. GitHub handles this information under its own privacy policy.

You can enter a different HTTPS catalog address. The operator of that address can receive normal request information and applies its own privacy policy.

CropPrint does not use responses from these requests for tracking, advertising, or analytics.

## Data collection

The CropPrint developer does not collect personal data through the application. CropPrint does not sell or share personal data.

## Changes

This policy will change if CropPrint adds a feature that changes its data practices. The effective date will identify the current version.

## Contact

For a privacy question, [open an issue in the CropPrint source repository](https://github.com/pvk2007/rapid/issues).
