# CropPrint support

CropPrint includes a Help page in both applications. Open that page for instructions about cropping, decorations, passport presets, and print sheets.

For a defect or support request, [open an issue in the CropPrint source repository](https://github.com/pvk2007/rapid/issues). Include the application version and Git SHA from the About page.

Do not attach a private photo unless the photo is necessary to reproduce the problem. Remove private information before you attach a file.
