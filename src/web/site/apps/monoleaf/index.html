Read and navigate

Keep the document and its context together

Open a Markdown file or a folder of documents. Switch between folders as workspaces, or keep several files open in tabs.

Find your place

Use Files, Contents, Links, and History in one left sidebar. Contents includes headings, tables, figures, equations, and diagrams.

Read rich Markdown

View tables, syntax-highlighted code, LaTeX equations, Mermaid diagrams, emoji, and local images. Copy source text, table data, or rendered diagrams and equations.

Choose your reading layout

Choose installed fonts, text sizes, and colors. Use Light, Dark, or System appearance, optional source line numbers, and paged or continuous views.

Return to your reading

Monoleaf remembers reading positions and settings locally. Choose automatic reload for changed files, or refresh when you are ready.

The first release targets macOS. iPhone and iPad versions are planned and are not yet available.

Local reading data

Highlight a passage, then add your thoughts

Monoleaf is a viewer, not a Markdown source editor. Highlights, comments, and Notes are saved separately in local application data.

  1. Select a passage in the rendered document.
  2. Open Annotations in the right sidebar and choose a highlight color.
  3. Add a comment about the selected passage, or switch to Notes for longer reading notes.
  4. Select an annotation to return to its passage. Search annotations or Notes to find earlier thoughts.

You can copy document text and paste into comments and Notes through standard Mac commands. Notes accept plain text or Markdown.

Your Markdown file stays unchanged until you explicitly export to that file. Copying the original file alone does not include your locally stored reading data.

Choose what to share

Export your annotations and notes when ready

Choose File > Export Reading Data to review the output choices.

  • Export an annotated copy to preserve the original document.
  • Export annotations, Notes, or both to a separate reading-data file.
  • Insert annotations after their source blocks, or collect them in a generated section.
  • Append Notes at the end of the document.

Annotations include the quoted passage, comment, section, and source line where available. Generated sections are marked and can be replaced on a later export.

Check the export destination before confirming. Exporting to the current file changes that file. Changes to the source can also move an annotation away from its original passage.

Help and privacy

Keep documents and reading data on your device

Monoleaf has no account, advertising, analytics, or app telemetry. Markdown, math, and diagrams render locally without an external rendering service.

Local images use access granted through the file picker. Remote images are blocked. External links open in your browser.

Use the built-in Help menu or the Monoleaf support guide. Read the Privacy Policy for app and website details. This website uses Google Analytics separately from the app.

For problems, include the app version, build, macOS version, and steps to reproduce. Use a public example instead of a private document or reading note.
