Purpose

One photo workflow for common output sizes

CropPrint opens one photo and places a fixed-ratio crop rectangle over the image.

Move or resize the rectangle while CropPrint preserves the selected ratio. The exported image contains only the selected area.

Precise cropping

Select a size and orientation. Then compose the photo without calculating pixels or distorting the image.

Physical print sheets

Tile passport or general photos on 4x6, 5x7, Letter, A4, and other paper sizes.

Text and frames

Place, resize, and rotate live text. Add a built-in frame or an approved downloaded frame.

Private by design

Your photo stays on your device. CropPrint has no account, analytics, advertising, or app telemetry.

Basic workflow

Crop a photo

  1. Open a photo. Use the File menu, Finder Open With, drag and drop, or the iPhone photo picker.
  2. Select a preset. Choose a print, passport, social, phone, MacBook, or monitor size.
  3. Select an orientation. Choose portrait or landscape when the preset supports both options.
  4. Compose the photo. Move the crop rectangle and drag a corner to resize it.
  5. Add decorations. Add live text or a frame when the photo needs those elements.
  6. Export the crop. CropPrint saves a new file and keeps the original unchanged.

On macOS, CropPrint can export JPEG, PNG, TIFF, or HEIC. On iPhone and iPad, CropPrint saves the result to Photos.

Correct physical dimensions

Create a passport or photo print sheet

A cropped passport photo and the paper usually have different physical sizes. A print sheet places exact-size copies on the paper.

  1. Select a physical preset. Choose a passport or general print size before you create the sheet.
  2. Open Create Print Sheet. Use the toolbar or the File menu after you finish the crop.
  3. Select the paper. Choose its size, orientation, image PPI, printer DPI, and optional cutting guides.
  4. Check the size. Review live pixel details or use the ruler-calibrated true-size preview.
  5. Save the sheet. The macOS app saves JPEG and PDF files. The iOS app saves a JPEG.
  6. Print at actual size. Use 100 percent scale and disable Fit to Page or borderless enlargement.

Check current passport rules before use. A preset controls the outer photo size only.

Government rules can also control head size, background, expression, photo age, and submission method.

Image PPI controls JPEG pixels. Printer DPI controls printer dots and does not change the physical print size.

Included targets

Print, identity, social, and screen presets

Print and identity photos

Use common print ratios or identity-photo dimensions for the United States, Canada, India, Europe, China, and parts of Asia.

Social media

Create exact output sizes for Instagram Story, Instagram Portrait, and Instagram Square.

Phones and MacBooks

Create backgrounds for supported iPhone and MacBook display sizes, including portrait and landscape options where applicable.

Monitors

Choose VGA through 8K UHD, including Full HD, DCI 2K, QHD, 4K, 5K, and 6K targets.

Digital presets resize the crop to exact pixels. Physical print presets preserve the available source pixels.

Live composition

Add text and photo frames

The text layer appears directly on the photo. Drag its box to move it and use its handles to resize or rotate it.

Change the font, style, size, color, opacity, and position. Each change appears in the preview.

Frame styles include classic, double, rounded, film, and Polaroid. You can control the frame color, width, and opacity.

CropPrint can download approved fonts and frames from listed sources. The app shows each resource license and attribution.

Support

Get help or report a problem

Use the built-in Help menu for interface guidance. Hover over a macOS toolbar icon to see its purpose.

Use GitHub Issues for support, defects, and feature requests.

Include the app version, Git SHA, operating-system version, steps, expected result, and actual result.

Do not send a private photo unless the image is necessary. Use a test photo when possible.

App privacy

Your photo remains on your device

CropPrint reads only the photo that you select. It writes only the exported photo or print sheet.

The app contacts a server only when you refresh or download optional fonts and frame resources.

CropPrint does not send photos, crop settings, analytics, telemetry, advertising identifiers, or personal data to Outcrop.

The Outcrop website uses Google Analytics for aggregate website metrics. That service is separate from the CropPrint app.
