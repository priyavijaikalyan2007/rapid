How to get help

Report a problem, request a feature, or ask how an application works.

CropPrint

CropPrint supports macOS and iPhone. It crops photos, creates print sheets, and adds optional text or frames.

Send support requests to {{contactLink}}.

You can also report a source-code issue in the public repository.

Information for a problem report

Include enough information to reproduce the problem:

  • The app version and Git SHA from the About page
  • Your macOS or iOS version
  • The steps that caused the problem
  • The result that you expected
  • The result that the app produced

Protect private content

Do not send a private photo unless the image is necessary to reproduce the problem.

If possible, use a test image or remove private details before you send a file.
