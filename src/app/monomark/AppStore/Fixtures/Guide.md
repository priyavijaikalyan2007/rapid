# Companion guide

## Reading data stays local

MonoMark stores reading positions, preferences, highlights, comments, and notes in its local application data.
The source document changes only when you explicitly export reading data to it.

## Review an export

Select Export Reading Data from the File menu. Choose an annotated copy and keep this example source unchanged.
Select annotations, notes, or both. Choose inline placement or a section at the end.
Exported comments and their highlighted quotations have separate labels. Notes appear at the end.
