# Monoleaf support copy

Monoleaf reads local Markdown files and folders on Mac. Open a document through the native Open command.
Use the left sidebar for files, contents, links, and reading history. The right sidebar contains annotations and Notes.

Highlights, comments, Notes, settings, and reading positions stay in Monoleaf's local application data.
Source files change only when you explicitly export reading data to them.
Export a copy or a separate reading-data file when you want to preserve the original document.
Keep a backup of reading data before removing the application or its local data.

If an external edit does not appear, select Refresh. Settings can enable automatic reload.
If a quotation no longer matches after an external edit, check its location before exporting inline comments.

Report a problem through [GitHub Issues](https://github.com/priyavijaikalyan2007/rapid/issues/new/choose).
Include the Monoleaf version, build number, source revision, macOS version, and steps that reproduce the problem.
The About dialog shows the build information. Use a small invented document when possible.
GitHub issues and attachments are public. Remove private paths, document text, comments, and screenshots before posting.
